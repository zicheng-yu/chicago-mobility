# 样本用途与抽样方式

样本用于查看字段、追溯来源和演示清洗，全部分析与图表均使用完整数据处理后的融合表。

每个处理分块在清洗前固定随机种子 42 抽取最多 5 条原始记录，并保留其中清洗后仍有效的对应记录。单车按月读取、每块最多 15 万行；出租车按日读取。因此样本覆盖全年来源文件，但不是用于总体估计的等概率样本。

- `raw_divvy.csv` 和 `raw_taxi.json`：来源记录的结构样本。
- `cleaned_divvy.csv` 和 `cleaned_taxi.csv`：同一批被抽中 ID 中，经过清洗仍保留的记录。
- `sampling_divvy.json` 和 `sampling_taxi.json`：抽样规则、种子、样本条数及来源文件清单。

附加字段 `_source_file` 仅用于标识对应的本机原始文件，不属于上游字段。其余原始字段保留来源含义；JSON 样本中的缺失字段可能以 null 展示。小样本作为本非商业课程研究的来源说明随代码提供，不作为独立运营数据集再分发。
