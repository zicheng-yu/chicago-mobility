## 完整数据核验

十二个月单车来源文件及三百六十六天出租车归档已完整采集。出租车各月与官方 count 对账，总计 6,480,350 条。单车全源 5,860,568 条中排除 144,337 条滑板车和 211 条重复记录，时长规则处理后保留 5,583,690 条。出租车清洗后保留 6,107,775 条。

日级表 366 行、小时表 8,784 行、社区日级表 28,182 行。两来源的日级与小时级总量等于各自清洗明细；社区总量等于清洗明细减去空间未匹配记录。独立流式 CSV 字节核算与数据框清洗的单车范围一致。

原始数据的字节数、SHA-256 和逐月条数保存在 file_manifest.csv、scale_audit.json、divvy_source_profile.json 与 data/metadata。大规模运营明细留在本机，提交材料附样本和重建脚本。

## 提交材料的复现

从 Git 暂存区导出独立目录，确认其中没有两类大型原始运营数据，仅使用随项目提供的完整融合表、质量记录和社区边界运行 analysis/analyze.py。重新生成的汇总字段一致，七张核心 PNG 的 SHA-256 全部与交付图相同，详见 reproduction_check.json。此检查验证分析材料可独立复现，不代替完整原始采集核验。
