# 统一数据表字段

## 清洗明细

| 字段 | 含义与单位 | 适用范围 |
|---|---|---|
| trip_id | 来源记录 ID，仅在各来源内部去重 | 两类记录，不跨源匹配同一次出行 |
| started_at | 芝加哥当地开始日期时间 | 两类记录 |
| ended_at | 来源结束日期时间 | 两类记录，允许缺失 |
| duration_seconds | 单车为起止差，出租车用官方 trip_seconds，单位秒 | 两类记录 |
| community_id | 起点所在社区编号，1 至 77 | 单车坐标落区，出租车官方编号 |
| rider_type | 单车会员或临时用户类别 | 单车，其余为空 |
| rideable_type | classic_bike 或 electric_bike，原始运营类型 | 单车，其他来源为空；滑板车已排除 |
| payment_type | 出租车支付方式 | 出租车，其余为空 |
| distance_miles | 来源提供的行程英里数 | 出租车，异常或未提供为空 |
| fare_usd | 来源提供的基础车费，美元 | 出租车，异常或未提供为空 |
| trip_total_usd | 来源提供的总费用，美元 | 出租车，异常或未提供为空 |
| date | 开始时间所属当地日期 | 两类记录的聚合键 |
| hour | 开始时间所属当地小时，0 至 23 | 两类记录 |

会员类型与支付方式具有不同语义，保留为不同列。未提供的单车里程和价格不从坐标或其他系统推测补齐。

## 融合表

`daily.csv` 一行对应一个当地日期；`hourly.csv` 一行对应日期与小时；`community_daily.csv` 一行对应日期与社区。原始记录先分别聚合，再用这些唯一键连接。

| 字段或字段组 | 含义 |
|---|---|
| divvy_trips / taxi_trips | 两个公开系统的清洗后记录次数 |
| mean_duration_min | 对应来源的平均出行分钟数，列名带来源前缀 |
| mean_miles / mean_fare_usd | 出租车有效里程或基础车费的日均值，单车列为空 |
| precip_mm | 两个天气站有效日降水的平均值，毫米，含降雪液态当量 |
| tmax_c / tmin_c | 两站有效日最高或最低温的均值，摄氏度 |
| tavg_c | 上述最高与最低温均值的平均，是温度代理而非逐时真均温 |
| snow_mm | 两站有效日降雪量均值，毫米 |
| wind_mps | 两站有效日均风速的均值，米每秒 |
| weather_stations | 当日原始站日记录数 |
| rain_day | 内部命名，实际表示 precip_mm 至少 1 mm 的降水日 |
| is_holiday / holiday_name | OPM 联邦节假日标记与名称 |
| dow / month | 当地星期，周一为 0；月份为 1 至 12 |
| day_type | 联邦节假日优先，其次周末，其余为普通工作日 |
| community_id / community_name | 社区编号与官方名称 |

社区和小时网格中补全的零，仅表示该系统公开数据在该组合下没有保留记录。空间未知记录保留在系统日级和小时级总量，只从社区表中排除。
